ToGo115 UI 重构 — 四套设计方案

以下方案基于项目特性（个人媒体自动化工具）和 Impeccable 设计原则， 从四个截然不同的美学方向切入，避免泛 AI 审美。

用户画像：技术爱好者 / HomeLab 玩家 使用场景：追剧管理 · 资源监控 · 系统配置 品牌调性：高效 · 专业 · 个性化

🎬 A. Noir Cinematic

暗色影院 · 进化现有方案

在现有 Netfl ix 暗色基因上做极致打磨。黑底上的光影层次、Hero 横幅的视觉冲击、横向滚动的卡片行——用电影级的构图语言浏览媒体内容。

暗色主题Netfl ix 风格沉浸式视觉优先渐变光影
实施难度：中等 — 已在 preview.html 有原型，打磨细节即可

⌨️ B. Terminal Modern

新粗野主义 · 极客工具箱

用等宽字体、高密度信息、类终端美学打造"黑客的工作台"。抛弃传统侧边栏，采用顶部状态栏 + 全宽命令行布局。信息密度极高，键盘驱动，专为效率而设计。

等宽字体高密度粗野主义键盘驱动类终端
实施难度：较高 — 需要大幅改变布局逻辑和信息架构

✨ C. Linear Clean

现代 SaaS · 极简仪表盘

借鉴 Linear / Vercel 的设计语言：浅色默认主题、微妙阴影层次、精确的间距系统、状态标签和数据可视化。侧边栏极窄（图标+Tooltip），内容区宽大，让数据自己说话。

浅色主题极简主义数据可视化Linear 风格状态驱动
实施难度：中等 — CSS 变量体系重构，布局调整适中

📖 D. Editorial Lounge

杂志编辑风 · 影音阅览室

以排版为核心的设计：衬线标题、宽裕留白、暖色调背景。布局像一本精致的影音杂志——大图封面、双栏文字、讲究的字距行距。浏览 TMDB 就像翻阅 Criterion Collection 目录。

暖色浅色衬线标题排版优先杂志风格宽裕留白
实施难度：中等 — 字体和比例改动较大，但布局结构可继承

💡 推荐思路

方案 A 风险最低、落地最快（已有原型参考）；
方案 C 现代化程度最高、最耐看，适合作为长期方向；
方案 D 个性最强，适合想要极致差异化的玩家；
方案 B 最硬核，适合追求效率的极客用户。

也可以 A + C 混合：保留暗色影院浏览体验 (A)，但用 Linear 的简洁布局和交互 (C) 重构管理页面。
